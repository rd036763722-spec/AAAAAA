# voice-ai

עוזר קולי לימות המשיח, בלי הגבלות נושאים.

## התקנה
1. מעלים את הקבצים ל-GitHub ומחברים ל-Render (render.yaml מוכן).
2. נכנסים ל-upstash.com, יוצרים מסד Redis חינמי ומעתיקים ל-Render שני משתנים: UPSTASH_REDIS_REST_URL ו-UPSTASH_REDIS_REST_TOKEN. זה כל מה שצריך ב-Render.
3. נכנסים ל-https://APP.onrender.com/admin, בוחרים סיסמה (בכניסה הראשונה) ומזינים את המפתחות וההגדרות.
4. בימות: שלוחת API לשיחה עם הכתובת /yemot/1 ושלוחת API להיסטוריה עם הכתובת /hist (הכתובות המדויקות מוצגות בדף ההגדרות).

## שימוש
- פתיח: "שלום אנא הקלט את ההודעה בסיום הקש סולמית" (אפשר לשנות או לבטל).
- חיפוש באינטרנט רק כשמבקשים: "סכם לי את החדשות היום חפש באינטרנט".
- שינוי קול באמצע שיחה: "תחליף לקול גברי", "דבר לאט".
- היסטוריה: שמיעה, המשך, מחיקה של שיחה או של הכול.

אופציונלי: ADMIN_PASSWORD ב-Render קובע סיסמת ניהול קבועה במקום הסיסמה שנבחרת בכניסה הראשונה.
